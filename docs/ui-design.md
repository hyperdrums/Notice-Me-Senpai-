# POP-TECH UI 設計指針

POP-TECH は、無彩色を基調に、ネオンアクセントと角切り・ハードシャドウでメリハリをつけるダーク固定のテーマです。

配色は「色を意味にだけ使う」方針です。強い色は少ないほど効き、操作・警告・期限という意味のある箇所にだけ割り当てます。それ以外は無彩色（ダークグレー＋白）に徹し、視覚ノイズを抑えます。

## カラーパレット

| 用途 | 変数 | 値 |
| --- | --- | --- |
| 背景（最深） | `--charcoal` / `--bg` | `#0A0A0A` |
| パネル背景 | `--bg-secondary` / `--panel` | `#1C1C1E` |
| 浮いた背景・操作面 | `--bg-elevated` / `--control-bg` | `#303030` |
| 枠線 | `--line` / `--control-edge` | `#4A4A4A` |
| 文字（主） | `--text` | `#FFFFFF` |
| 文字（控えめ） | `--muted` | `#BDBDBD` |
| 操作・選択 | `--lime` / `--accent-primary` | `#C8F000` |
| 操作の縁（濃いライム） | `--accent-edge` | `#8FAE00` |
| アクセント上の文字 | `--text-on-accent` | `#000000` |
| 警告 | `--accent-danger` / `--danger` | `#FF2442` |
| 警告文字（補足） | `--danger-text` | `#FF625C` |
| 期限間近 | `--accent-yellow` / `--soon` | `#FFE000` |
| ハザード縞（クリーム） | `--hazard-cream` | `#F5F1E7` |
| 影 | `--shadow` | `#000000` |

## 配色のルール

- **ライム `#C8F000`** は操作・選択とそのフィードバックに使う。選択中のタブ・チップ、接続線、フォーカスリング、更新時刻のフラッシュ、スクロールバーのホバー。
- **コーラル `#FF2442`** は「警告」にだけ使う。期限超過、インシデント種別、警告ピン、×（閉じる）ボタン。
- **黄 `#FFE000`** は「期限間近」にだけ使う。3 日以内の期限。
- **無彩色が基本**。アサイン・メンションなどの種別ラベルや、チップの件数バッジは無彩色。タスクバーなどの通知バッジにはブランド色 `#E24329` を許容し、MR 状態には記号のみに状態色を使う。

ライム・コーラル・黄をそれぞれ操作・警告・期限に割り当てる機能上の理由が明確であること。安易に色を増やさない。

## デザイン語彙

- **角切り（clip-path）**: パネルや操作面の角を斜めに切り落とす。パネルは `13px`、カードや小要素は `9px`。角切りは操作面を見分ける手がかり。
- **ハードシャドウ**: `3px 3px 0` の黒オフセット影（選択中は `4px 4px 0`）。影の輪郭は角切りに沿わせる（`filter: drop-shadow`）。
- **ホバーで浮き上がり**: ボタンやチップを `translateY(-2px)` で持ち上げる。ピル型タブは文字色で反応し、カードは右へ 2px 動かして左辺にライムの帯を出す。
- **タイトルバーバナー**: 透過ロゴ素材を `8px center / auto 26px` で配置。下端 7px にクリームとチャコールのハザードストライプ（`repeating-linear-gradient`）を重ねる。
- **ピクセルドット**: セクション背景のドットパターン。装飾を最小限に。
- **警告ピン**: コーラル地に白い「!」を載せた 12px のティアドロップ。Items タブの左側では先端をピルトラックの上枠から約 6.99px 沈め、絞り込みチップの左上では先端を約 4.99px 重ねる。期限超過の件数はツールチップ／読み上げで伝える。
- **押せる／押せないの区別**: ボタンやチップは面の塗りや影を持たせ、種別ラベルは塗りなしで表示する。
- **階層は面の色でずらす**: プレート（`#303030`）の上に載せる操作要素は面を同色にせず一段明るくする（✓ ボタン＝白、MR チップ＝`#4a4a4a`）。同色を重ねると影だけでは高さが伝わらない。

## レイアウトと操作

- **スクロール**: `body` はウィンドウの高さに収め、縦方向の flex と `overflow: hidden` で固定する。Activity / Items のペインは残りの高さを使い、一覧の `ul` だけを縦にスクロールさせる。タイトルバー、ヘッダー、チップバーはその場に残す。設定はペイン自体をスクロールさせる。
- **スクロールバー**: 幅 8px。トラックを透明にし、つまみの左右に透明な境界を各 2px 取るため、実効幅は 4px。つまみは通常は枠線色、ホバーでライムにする。
- **最終更新時刻**: 更新ボタンの左に `HH:mm:ss` を 10px の等幅フォントで表示する。最初の To-Do 取得が成功するまで隠し、一覧を更新したときや取得エラーから復帰したときに時刻を更新する。変更時はライムで光り、0.6 秒で控えめな文字色へ戻す。
- **タブのピルセレクタ**: ピル型のトラックに Activity・Items・設定を並べる。選択中のタブの位置と幅にライムのインジケーターを合わせ、切替時は 150ms でスライドさせる。
- **タブ切替のスワイプイン**: メインペインの表示要素を、タブの並びに沿って右へ進むときは右から、左へ戻るときは左から、24px 移動させながら 220ms でフェードインする。チップバーなどはすぐに始め、一覧の行は 35ms 刻みで遅らせる（最大 350ms）。

### 接続線

- 選択中のリポジトリチップから分類チップへ、太さ 2px のライムの線を引く。カードをホバーすると、分類チップからカードの見えている左辺の中央へ線を伸ばす。
- カードへ向かう線は、一覧の上で左へ曲げ、カード左辺から 12px のガターを通す。終点は左辺の 4px 手前とし、途中のカードにも重ねない。
- リポジトリのチップバーが 2 段に折り返し、選択中のチップの下に別の段があるときは、バー左端から 4px のレーンに回して下段を避ける。分類チップが表示されないときは、リポジトリチップからホバー中のカードへ直接つなぐ。この場合も下段があれば左レーンを使う。

## アクセシビリティ

- **色だけに頼らない**（WCAG 1.4.1）: MR 状態は記号、期限は文言でも判別できる。
- **フォーカスリング**: ライム `3px`、`outline-offset: 2px`。キーボード操作を可視化。
- **`prefers-reduced-motion`**: ホバー移動やトランジション、接続線の描画アニメーション、更新時刻のフラッシュを無効化し、タブ切替のスワイプインを省く。
- **ダーク固定**: `color-scheme: dark` を CSS と `<meta>` の両方で宣言し、OS の明暗設定に追従しない。

## フォント

- ブランド・数値・ラベル: `--mono-font`（Consolas / Cascadia Mono / Yu Gothic UI, monospace）
- 本文: Segoe UI / Yu Gothic UI, sans-serif

## 設計経緯

初期のデザイン検討では、都市型ゲームの UI（例: 『ゼンレスゾーンゼロ（Zenless Zone Zero）』）の配色と角切り・硬質な影の語彙を参考にしました。配色・装飾はすべて独自に構成しており、特定ゲームの素材・画面構成の転載ではありません。
